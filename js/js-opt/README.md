# JS-OPT — оптимизация обработки данных

В работе выполнены задания 1–7. Исходные тестовые данные и функции Slow сохранены. Для сравнения используется проверка совпадения результатов и медиана пяти серий замеров.

## Что изменено

1. **Поиск товара по ID** — использован `find()`, который останавливается на первом совпадении.
2. **Фильтрация по списку ID** — список выбранных ID заранее преобразуется в `Set`; порядок товаров сохраняется фильтрацией исходного массива.
3. **Удаление повторов** — использован `Set`, который сохраняет порядок первого появления и различает строки с разным регистром.
4. **Многократный поиск по ID** — создан `Map` по ID, после чего запросы выполняются через `get()`; повторы и отсутствующие ID сохраняются в результате.
5. **Статистика заказов** — количество и сумма накапливаются за один проход. Неизвестные статусы пропускаются, порядок известных статусов сохраняется.
6. **Самый дорогой товар** — максимум ищется одним проходом без сортировки; при равной цене остаётся первый товар.
7. **Сводка по категориям** — показатели всех категорий обновляются за один проход по товарам.

## Проверка и замеры

Запуск: `node optimisation_lab.js`
